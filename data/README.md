# data/

Scraper'ların indirdiği JSON'ları buraya koy, sonra `index.html`'de **Klasör seç** ile bu klasörü seç.

- Tanınan adlar: `<site>-siparisler*.json` ve başka hesap için `<site>-<ek>-siparisler*.json` (ör. `trendyol-hesap2-siparisler.json`). Aynı sitenin dosyaları panelde tek mağazada birleşir.
- Bu klasördeki `.json` dosyaları git'e girmez (`.gitignore`).
